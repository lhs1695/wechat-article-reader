# 模块说明

运行时数据在 `.runtime/`，导出默认在 `output/`，均不提交。源码在 `src/wechat_article_reader/`。

## 包职责

| 包 | 职责 |
| --- | --- |
| `domain` | 文章聚合、来源、内容值对象、四字段摘要；URL 规则 |
| `application` | `fetch` / `summarize` / `export` / `batch` 用例；scraper / summarizer / storage / exporter 端口 |
| `features/article_reading` | HTML→blocks 投影、Markdown 渲染、ingest/元数据/分页/按节跳读 |
| `features/article_workflow` | CLI/Web/MCP 共用的抓取、摘要、导出、批处理门面 |
| `infrastructure/adapters` | `WechatHttpxScraper`、DeepSeek、HTML/Markdown 导出 |
| `infrastructure/persistence` | SQLAlchemy 模型、仓储、UoW、Alembic |
| `infrastructure/config` | Settings、路径、DI 容器 |
| `presentation/cli` | Click：fetch / read / batch / web / mcp-server / db / cache / check |
| `presentation/web` | FastAPI 页面与 `/api` |
| `mcp` | FastMCP 工具、校验、错误映射、stdio/HTTP 入口 |
| `shared` | 常量、异常、SSRF、HTML 安全、日志、提示词 |

## 阅读相关文件（改分页先看这里）

- `features/article_reading/projection.py`：HTML 走查与分块
- `features/article_reading/renderer.py`：块 → Markdown
- `features/article_reading/service.py`：ingest、toc_level、section、软分页、文头
- `features/article_reading/dto.py`：对外序列化字段
- `mcp/toolsets/reading_tools.py`：工具参数与 docstring（契约给 Agent 看）
- `mcp/input_validator.py`：URL / UUID / toc_level / section
- `mcp/error_mapping.py`：异常 → `MCPToolError`

## 摘要相关

- `features/article_reading/summary_renderer.py`：给模型的输入 Markdown（与阅读页可以不同，但仍来自同一投影）
- `infrastructure/adapters/summarizers/deepseek.py`：一次调用、校验 JSON
- 输出约定：`overview`、`key_points`、`tags`、`one_sentence`

## 测试入口

| 文件 | 覆盖 |
| --- | --- |
| `tests/test_article_reading.py` | 投影、分页、跳章、toc |
| `tests/test_mcp_reading_tools.py` | MCP 阅读工具契约 |
| `tests/test_mcp_article_tools.py` | 摘要工具 |
| `tests/test_cli_read.py` | CLI read |
| `tests/test_web_markdown.py` | Web 与阅读服务复用 |
| `tests/test_deepseek_summarizer.py` | 模型 JSON / 超长拒绝 |

项目只服务微信公众号的抓取、阅读、摘要与导出。不包含知识库、OCR、图片理解、跨文章分析或内部 Agent 运行时。
